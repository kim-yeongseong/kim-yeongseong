## 🎯 Mindset

### 🤖 AI와 함께 일하는 개발자
AI(Claude, Cursor, Copilot 등)를 **"단순 코드 생성기"가 아닌 "함께 리뷰하고 토론하는 협업 파트너"** 로 활용합니다.

회사에 Claude Code 도입을 적극 제안해 승인받고, **CLAUDE.md 공통 컨텍스트 문서 체계**를 3개 리포지토리에 정착시켰습니다.

### 🔍 작은 질문도 끝까지 따라가는 편
작은 이슈 속에서도 **이유와 원인을 끝까지 탐구**하며 더 나은 해결책을 찾습니다.

### 🤝 협업과 의사소통이 핵심
기술적 역량을 갖춘 이후에는 **협업과 의사소통, 함께 고민할 수 있는 역량**이 더 중요하다고 믿습니다.

### 📚 지속적인 학습과 성장
**학점은행제 학사 과정(휴넷·컴퓨터공학과) 진행 중** · **정보처리기사 필기 합격** 후 실기 준비 중
